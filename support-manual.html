⚡ Features Guide

How every feature works — so you can explain it to users.

📊 Stock Analysis

The core feature. User types a ticker (e.g. AAPL) in the search box and clicks Analyze.

What loads on the results page:

  • Quote card — live price, change %, day range, market cap
  • Chart — TradingView interactive chart with multiple timeframes
  • Indicators — RSI, MACD, Bollinger Bands, EMA Crossover, Volume, Stochastic
  • Level II & T&S — bid/ask depth, time and sales (delayed)
  • Valuation — P/E, P/B, PEG, EV/EBITDA ratios
  • Fundamentals — revenue, earnings, margins, balance sheet
  • Technical — moving averages, support/resistance, trend signals
  • Short Interest — short float %, days to cover, FTD data
  • Company — profile, description, sector, employees
  • Financials — income statement, balance sheet, cash flow
  • Intelligence — analyst ratings, price targets, upgrades/downgrades
  • Insider — SEC Form 4 transactions (buys/sells by insiders)
  • SEC Filings — 10-K, 10-Q, 8-K, proxy filings via EDGAR
  • News — last 30 days, paginated, "Load older news" for history
  • AI Analysis — deep analysis button + Ask PulseAI chat
  • Community — sentiment votes and room link for that stock

🤖 Ask PulseAI Chat

Appears in the AI Analysis section after analyzing a stock. Uses live price data and recent news to answer questions.

Quick chips available:

  • 📊 Why moving today?
  • ⚠️ Key risks
  • 📈 Analyst views
  • 💰 Good buy now?
  • 🚀 Catalysts
Note: Chat uses live Finnhub price data + recent headlines for context. Quality of answers depends on available data. Not financial advice.

📰 News Section

Shows last 30 days of news by default, paginated at 10 articles per page.

  • Use the dropdown to change the date range (7 days / 2 weeks / 30 days)
  • Click "Load older news ↓" at the bottom to fetch 30 more days
  • Can go back up to 1 year for most stocks
  • For high-volume stocks like AAPL, 7 days fills 5 pages quickly

📱 Ticker Bar

The scrolling bar at the top showing live prices. Shows indices (SPY, QQQ, GLD etc) plus individual stocks.

  • Click ✏️ Edit to add/remove stocks from the ticker bar
  • BTC and ETH are not supported (Finnhub free tier limitation)
  • Updates every time the page loads

💼 Portfolio

Personal portfolio tracker stored in the user's browser (localStorage).

  • Type a ticker in the input and click + Add to add a holding
  • Prompts for shares and avg cost (both optional — can enter 0)
  • When adding, asks "Also add to ticker bar?" — user can choose
  • Click − Remove with ticker in input to remove a holding
  • Shows live P&L, total value, day change
Important: Portfolio data is stored in the browser only — it will be lost if the user clears browser data or switches browsers. Cloud sync is a planned feature.

🖥 Desktop Ticker App

A separate Electron app that shows a floating ticker bar on the desktop.

  • Available at /desktop page for download
  • Mac only currently (Intel x86_64)
  • Run: open the downloaded app, allow in Security & Privacy settings if blocked
  • Right-click to edit which tickers display

🔑 Account & Authentication

How user accounts work across PulseStock.

Single Sign-On: One Supabase account works across the main app AND community. Users sign in once at /signin and are automatically logged into community.

🔐 Sign Up Process

1

User goes to /signin

Fills in username (3+ chars), email, and password (6+ chars)

2

Account created in Supabase Auth

Email + password stored securely. A profile record is created with username and random avatar color.

3

Redirected to main app

User's name appears in the top-right nav. Avatar click goes to community.

🔓 Forgot Password

If a user says they can't log in or forgot their password:

1

Direct them to /signin

Tell them to enter their email address in the Sign In form

2

Click "Forgot password?"

Link appears below the Sign In button. Supabase sends a reset email.

3

Check email

Reset link expires in 1 hour. Tell them to check spam if not received.

If email not received: Check Supabase Auth → Users to confirm the email exists. If not found, the user may have signed up with a different email.

🔔 Trade Detection Feature

When a user types a trade in chat (e.g. "bought AAPL at 291 target 310 stop 280"), a blue banner appears asking if they want to create a formal pick.

  • Detected keywords: bought, long, buy, sold, short, sell, calls, puts
  • Automatically extracts ticker, direction, entry, target, stop
  • User clicks "Add Pick" to pre-fill the pick form
  • If user reports banner not appearing — remind them it only triggers for their own messages

📈 Picks & Leaderboard

How trade picks, performance tracking, and the leaderboard work.

📝 Posting a Pick

1

Go to Community → Picks tab

Click the "Picks" tab in the community sidebar

2

Fill in the form

Ticker (required), Direction (BUY/SELL), Entry price, Target price, Stop loss, Notes (optional)

3

Live price is snapped

At the moment of posting, the current live price is automatically recorded as the actual entry price — users cannot manipulate this.

4

Pick appears as ⏳ Pending

Stays pending until the user closes it manually or it hits target/stop

🔒 Closing a Pick

Only the pick's author can close it.

  • Find the pick in community — a "Close Pick" button appears on their own picks
  • Click Close Pick → system fetches the current live price
  • Shows confirmation: "Close AAPL at $295.00? Return: +1.37%"
  • On confirm: exit price, exit time, and return % are saved automatically
  • Result set to WIN (positive return) or LOSS (negative return) automatically
Integrity note: Both entry AND exit prices are pulled from live Finnhub data — users cannot manually enter prices, ensuring an honest track record.

🐛 Reporting a Bug

When a user reports a bug, collect this information before escalating:

  • Browser & OS — e.g. "Chrome 124 on Mac"
  • Steps to reproduce — exactly what they did
  • Expected vs actual — what should happen vs what happened
  • Screenshot or error message — if available
  • Ticker/stock involved — if relevant
  • Time of occurrence — helps correlate with server logs
Common non-bugs: "Data not updating" during after-hours (market closes at 4pm ET), "Chart not loading" on slow connections (refresh fixes), "Insider data empty" for very small stocks (Finnhub free tier limitation).

❓ Common Issues & Solutions

Quick reference for the most frequent support questions.

🔧 Technical Issues

Chart isn't loading / showing blank
1. Hard refresh: Cmd+Shift+R (Mac) or Ctrl+Shift+R (Windows)
2. Clear browser cache
3. Try a different browser
4. Check if TradingView.com is accessible (chart is powered by TradingView)
Data showing as "—" or "N/A"
This is normal for: small/micro-cap stocks (limited Finnhub data), very new companies, ETFs and indices (no P/E ratio etc). If happening for major stocks like AAPL or MSFT, it may be a temporary API issue — try again in a few minutes.
Ticker bar showing "Loading market data..."
This means the Finnhub API call failed. Usually resolves on page refresh. If persistent, may be a Finnhub rate limit — should clear within 60 seconds.
Indicators section is empty
Indicators use simulated price data based on the live quote. Ensure the stock has a valid price loaded (shows in the quote card). If quote shows $0.00, the ticker may be invalid or delisted.
AI Analysis stuck on "Analyzing..."
The AI call timed out. This can happen with very long analysis prompts. Refresh the page and try again. If consistently failing, check Vercel runtime logs for API errors.
News section shows no articles
Try changing the date range dropdown to "Last 30 days". Some smaller stocks have limited news coverage on Finnhub. This is a data availability limitation, not a bug.

👤 Account Issues

Can't log in to community after logging into main site
Both use the same Supabase account. If still showing logged out in community: 1) Try a hard refresh 2) Sign out and back in at /signin 3) Clear cookies for pulsestock-nu.vercel.app
Portfolio data disappeared
Portfolio is stored in browser localStorage. It will be lost if: browser data was cleared, user switched to a different browser, used private/incognito mode. Cloud sync is planned. Apologize and note this is a known limitation.
Username already taken during signup
Usernames are unique across the platform. Ask the user to choose a different username. We cannot reassign usernames from other accounts.

📈 Community / Picks Issues

Can't post a pick — form not submitting
Must be logged in to post picks. Check they're signed in (name should show in header). All required fields (ticker, direction, entry, target, stop) must be filled.
"Close Pick" button not appearing
The Close Pick button only appears on picks you posted yourself, and only while the pick is still open (pending). If the pick already has a result (win/loss), it cannot be closed again.
Chat messages not sending
User must be logged in and have a valid profile. Check they're in an active room (not a room that was deleted). If input shows "Sign up or log in to chat" — they need to authenticate first.

📜 Policies & Guidelines

Key policies every support staff member must know.

⚖️ Financial Advice Policy

CRITICAL: PulseStock is an analysis tool, NOT a financial advisor. Support staff must NEVER give personalized investment advice, tell users to buy or sell specific securities, or imply that any analysis is a guarantee of returns.

Always include this disclaimer when discussing stock analysis features:

"PulseStock provides data and AI analysis tools for informational purposes only. This is not financial advice. Always consult a qualified financial advisor before making investment decisions."

🔐 Data Privacy Policy

  • Never share a user's email, username, or account details with other users
  • Never confirm whether a specific person has an account
  • Data deletion requests must be processed within 72 hours — escalate to admin immediately
  • Do not access user data beyond what's needed to resolve the support ticket
  • All access to Supabase is logged — use your assigned credentials only

💬 Communication Standards

  • Always professional — even if the user is rude or frustrated
  • Never argue — acknowledge their frustration, focus on solutions
  • Be honest — if you don't know, say so and escalate. Don't guess.
  • No promises — don't promise features or fixes unless confirmed by engineering
  • Response time — acknowledge within 2 minutes, resolve within 10
  • Sign off every conversation — confirm resolution before closing

🚫 Community Rules (Enforce These)

  • No pump & dump schemes or coordinated buying
  • No guaranteed return claims ("This stock will go to $500!")
  • No harassment, threats, or hate speech
  • No spam or self-promotion
  • No sharing of personal financial information (account numbers, SSN etc)
  • Stock picks must use the formal picks system — not just chat messages
  • Debate is welcome, personal attacks are not
