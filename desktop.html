PulseStock Desktop Ticker

A persistent ticker bar that lives at the top of your screen. Live quotes, one-click analysis, rotating broker ads — always visible while you work.

Download for Mac

Free · Requires macOS 10.15+ · Intel & Apple Silicon

⬇ Download from GitHub 📦 Download ZIP
1

Install Node.js

Download and install Node.js LTS from nodejs.org if you don't have it. Run node --version to check.

2

Download & Extract

Download the ZIP above and extract it. Or clone with:
git clone github.com/mscharbo-commits/pulsestock-ticker

3

Install & Launch

Open Terminal in the folder and run:
npm install
npm start 2>/dev/null

$ git clone https://github.com/mscharbo-commits/pulsestock-ticker
$ cd pulsestock-ticker
$ npm install
$ npm start 2>/dev/null
📊

Live Quotes

Real-time prices and % change for your custom ticker list. Updates every 15 seconds via Finnhub.

🔍

One-Click Analysis

Type any ticker and hit Enter — opens the full PulseStock AI analysis in your browser instantly.

📌

Always Visible

Pins to the top of your screen. Works across all your apps — Chrome, Terminal, Excel, anything.

⚙️

Customizable

Right-click to edit your ticker list. Add or remove any stock. Settings persist across restarts.

🚀

Auto-Launch

Starts automatically when your Mac boots. Always there when you need it, invisible when you don't.

Free
