Get the Desktop Ticker

Free · macOS 10.15+ · Requires Node.js

⬇ Download ZIP View on GitHub ↗
1

Install Node.js

Download from nodejs.org if you don't have it. Verify: node --version

2

Download & Unzip

Download the ZIP above and extract it anywhere on your Mac.

3

Run in Terminal

Navigate to the folder and run the three commands below.

$ cd ~/Downloads/pulsestock-ticker
$ npm install
$ npm start 2>/dev/null
# Bar appears at the top of your screen
# Right-click to edit ticker list · ✕ to close
