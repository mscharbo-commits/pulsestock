Download for Mac

Free · macOS 10.15+ · Intel Mac · Requires Node.js

⬇ Download ZIP View on GitHub ↗
1

Install Node.js

Download Node.js LTS from nodejs.org. Verify with node --version in Terminal.

2

Download & Extract

Download the ZIP above and extract it to your Downloads folder.

3

Launch

Open Terminal, navigate to the folder, run the commands below.

$ cd ~/Downloads/pulsestock-ticker
$ npm install
$ npm start 2>/dev/null
# Ticker bar appears at the top of your screen
